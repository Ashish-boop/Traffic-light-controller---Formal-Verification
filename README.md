# Traffic-light-controller---Formal-Verification
Traffic Light Controller Formal Verification (Cadence JasperGold) — Performed formal verification of a traffic light controller RTL design using Cadence JasperGold and SystemVerilog Assertions (SVA). Verified correct state transitions, timing sequences, reset behavior, mutual exclusion of traffic signals, and safety conditions under all operating scenarios. Utilized bounded proofs, assertion-based checks, and counterexample analysis to validate corner-case behavior and ensure robust controller operation.
